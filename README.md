# Projetos_web
 
Este repositório guarda os projetos web desenvolvidos durante as aulas do curso de Análise e Desenvolvimento de Sistemas.
 
## Conteúdo
 
Cada atividade fica em sua própria pasta, com os arquivos necessários para visualizar o resultado.
 
## Como visualizar
 
Para abrir um projeto, entre na pasta correspondente e abra o arquivo `index.html` no navegador.
